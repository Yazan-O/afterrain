# Data sources and licences

The code is MIT-licensed (`LICENSE`). The data in `data/raw/` and everything derived from it in `data/out/` keep the licences of their sources, listed below. Every cached file has a row in `data/raw/manifest.json` with its URL, download time (UTC), licence and size.

| Source | What Sayr uses | URL | Licence |

| OpenStreetMap, via the Overpass API | Waterway lines for the Avon and Frome catchment and the five OneAquaHealth cities | `https://overpass-api.de/api/interpreter` | ODbL 1.0, (c) OpenStreetMap contributors |
